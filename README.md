# Organizador-de-Archivos-mediante-rutas
# Python3
#==DESCRIPCION==#
Organizador sencillo de archivos/carpetas en Python3, mediante rutas pensado para intentar usarse en Windows y Linux, similar ala terminal tipo mini shell

#==REQUISITOS==#
Python 3.x
No requiere librerias externas (usa modulos como os, shutil y pathlib)

#==COMO USARLO==#
1. Copea o descarga el codigo con extension .py
2. Ejecuta el codigo en tu terminal como python3 "nombre_del_archivo".py
3. Indicar que quieres organizar tus archivos
4. Escoje la opcion que deseas hacer
5. Introduce la ruta. Ejemplo: Carpeta/Carpeta/archivo
6. Necesitas declarar bien el nombre de la carpeta y de tu archivo
7. Siempre al final es el nombre del archivo que deseas mover, borrar, copiar, etc
8. Siempre y cuando sea archivo, si es carpeta con la pura ruta (Carpeta) es suficiente
