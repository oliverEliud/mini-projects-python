#==DESCRIPCION==# Organizador sencillo de archivos/carpetas en Python3, mediante rutas pensadas para intentar usar en Windows y Linux, similar ala terminal tipo mini shell

#==REQUISITOS==# Python 3.x No requiere librerías externas (usa módulos como os, Shutil y Pathlib)

#==COMO USARLO==#

Copea o descarga el código con extensión .py
Ejecuta el codigo en tu terminal como python3 "nombre_del_archivo".py
Indica que quieres organizar tus archivos
Escoge la opción que deseas hacer
Introduce la ruta. Ejemplo: Carpeta/Carpeta/archivo
Necesitas declarar bien el nombre de la carpeta y de tu archivo
Siempre al final es el nombre del archivo que deseas mover, borrar, copiar, etc.
Siempre y cuando sea archivo, si es carpeta con la pura ruta (Carpeta) es suficiente
